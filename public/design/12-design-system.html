글자 대비

작은 글자 기준 4.5:1 이상 (자동 계산).

조합라이트다크글자 / 배경17.0:121.0:1흐린 글자 / 배경6.1:17.3:1흐린 글자 / 면6.4:15.9:1긴급 / 긴급 바탕4.8:16.5:1주의 / 주의 바탕5.4:17.4:1완료 / 완료 바탕4.6:17.4:1정보 / 정보 바탕5.7:17.4:1포인트 진한 / 포인트 연한6.9:110.0:1주 버튼 글자 / 주 버튼17.7:121.0:1

모두 4.5:1 이상이어야 해요(작은 글자 기준). 노란 포인트(--pop) 위에는 흰 글자를 쓰지 않아요.

쓰는 규칙

시안을 고치거나 새 화면을 만들 때 지켜요.

  • 색은 이 보드의 이름(--bg, --crit …)으로만 써요. 화면에 색 코드를 직접 적지 않아요.
  • 노랑은 한 화면에 한 곳만 강조해요. 상태(늦음·주의·완료)는 노랑이 아니라 상태 색을 써요.
  • 상태는 색과 글자를 함께 보여 줘요. 색만으로 구분하지 않아요 (예: 빨간 점 + "늦음 1"). 할 일 긴급도는 긴급·주의·확인·정리·바로 가능 5단계.
  • 할 일 줄은 제목 한 줄(넘치면 말줄임) + 설명 두 줄까지.
  • 주 버튼(검정)은 한 화면에 하나. 나머지는 보조 버튼이나 이어서 하기 칩으로.
  • 누르는 곳은 높이 36 이상, 탭바와 주 버튼은 44 이상.
  • 다크 모드는 같은 이름에 값만 바뀌어요. 다크에서는 그림자를 없애고 선으로 나눠요.
